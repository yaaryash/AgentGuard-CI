# AgentGuard CI

AgentGuard CI is a developer-focused prototype for testing
and detecting behavioural and security regressions in AI agents.

## Current Progress

- FastAPI backend
- Customer support refund agent
- Groq LLM integration
- Function/tool calling
- Order retrieval tool
- Refund policy tool
- Refund execution tool

## Architecture

User → LLM → Tool Call → Python Function → Tool Result

## Goal

Detect risky changes in AI agent behaviour and integrate
AI assurance checks into CI/CD pipelines.

## Tech Stack

- Python
- FastAPI
- Groq
- Docker
- PostgreSQL
- React
- GitHub Actions
